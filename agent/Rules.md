# Rules
In this file you will find rules for AI agents.

1. You should always keep the conversation compact, clear, and short
2. You should always keep track of the project's status in Track.md
3. You should run relevant tests after changes and report the results but be carefull with homomorphic tests, they can take a lot of resources and time.
4. You should update the project structure file (Structure.md) when you make changes, otherwise you should keep it as reference
5. You should keep a very compact version of the steps or changes you do as you memory in Memory.md
