# Agent Instructions

Before working on this project, read the files in the `agent/` directory:

1. `agent/Track.md` for current tasks, priorities, and progress.
2. `agent/Memory.md` for durable project context and prior decisions.
3. `agent/Structure.md` for the codebase structure and important files.
4. `agent/plan.md` for active and completed implementation plans.
5. `agent/aos.md` for the AoS implementation specification and algorithms.

Keep these files accurate as the project evolves. Update `Track.md` when task
status changes, `Memory.md` when a durable decision or lesson is established.

Important: Keep the conversation with user as compact as possible, only give very important information.
